Política de Privacidade

Turma do Nino · última atualização: 28 de outubro de 2026

Sobre o canal

A Turma do Nino é um canal infantil no YouTube, com vídeos marcados como “conteúdo para crianças”. Este site não usa cookies, JavaScript, formulários nem ferramentas de análise ou rastreamento, e não coletamos, vendemos nem compartilhamos dados pessoais de quem assiste aos vídeos ou visita o site. Nunca pedimos dados de crianças.

Uso dos Serviços de API do YouTube

A ferramenta interna que publica os vídeos do canal usa os Serviços de API do YouTube (YouTube Data API). Ao usar essa ferramenta, você também concorda com os Termos de Serviço do YouTube, e os dados tratados pelo YouTube seguem a Política de Privacidade do Google.

Dados acessados

A ferramenta acessa somente:

  • o próprio canal Turma do Nino, para enviar e agendar os nossos vídeos, thumbnails e playlists (YouTube Data API);
  • a nossa própria planilha de planejamento dos episódios (Google Sheets API).

Não acessamos dados de outras pessoas, inscritos ou espectadores. O token de acesso OAuth fica guardado localmente, no computador do responsável pelo canal, e nunca é enviado a terceiros. O uso de informações recebidas das APIs do Google segue a Política de Dados do Usuário dos Serviços de API do Google, incluindo os requisitos de Uso Limitado.

Armazenamento e exclusão

Não armazenamos dados recebidos da API além do próprio token OAuth. Para revogar o acesso a qualquer momento, remova a permissão em https://myaccount.google.com/permissions ou apague o arquivo local secrets/token.json.
